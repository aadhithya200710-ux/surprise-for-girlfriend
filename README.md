# Birthday Surprise for Muhsii ❤️

A magical, cute, emotional, cinematic birthday surprise website created with love by **Aadhiii** for **Muhsii**.

## Features

- 🌟 **Magical Background**: Interactive particle sky with floating hearts, sparkles, and glowing aura.
- 🎈 **Balloon Memory Surprise**: Pop balloons one by one to reveal special memory photos with smooth entrance and exit transitions.
- 🎂 **Interactive Candle Blowing**: Blow into your microphone (or tap the fallback button) to blow out the birthday candle with smoke & sparkler effects.
- 💌 **Animated Personal Letter**: Unfold a handwritten-style love letter from Aadhiii.
- 🎁 **Surprise Gift Box**: Unwrap a glowing gift box full of magical hearts.
- 🧸 **Dudu & Bubu Hug Animation**: Cute side-by-side walk and hug animation for Dudu (Aadhiii) and Bubu (Muhsii).
- 🎵 **Custom Music Player**: Beautiful spinning vinyl player featuring local audio.
- 🎉 **Grand Birthday Celebration**: Confetti burst and heartfelt birthday wishes.
- 🎬 **Cinematic Final Video**: Custom video container to relive sweet moments.
- ✨ **Peaceful Ending**: Touchingly closes the birthday journey.

## Tech Stack

- **Vite**
- **Vanilla JavaScript (ES6+)**
- **HTML5 & CSS3**
- No heavy frameworks, zero external UI libraries.

## Development & Build Instructions

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production (output directory: dist/)
npm run build

# Preview production build locally
npm run preview
```

## Vercel Deployment

This project is configured as a static Vite web application and is ready for Vercel deployment:

- **Framework Preset**: Vite
- **Build Command**: `npm run build`
